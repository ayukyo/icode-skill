# ICODE v2.37.1 — 紧凑阅读布局与大历史发现预算

文档阅读页使用类似 IDE 的紧凑布局开关，隐藏导航时完全释放阅读空间；同时调整大规模认证历史的默认扫描时间预算。

- 工程导航、章节导航和章内目录改为同一工具栏中的 SVG 图标按钮。默认按钮28×28 CSS px、图标16×16 CSS px，触控环境扩大到36×36 CSS px；悬停提示和可访问名称随展开状态同步。
- 工程导航收起后整个侧栏退出布局，不再保留48px窄栏。恢复入口位于当前可见工具栏；文档与工单页复用同一组控件，Windows原生文档页继续省去冗余网页顶栏。
- 保留独立切换、原有偏好、专注阅读快照、焦点回收和当前可见段落。没有新增运行时资源文件或依赖，也未改变文档API及通信方式。
- 阶段历史发现的默认时间预算从30秒调整为120秒，以容纳较大的认证历史扫描。时间预算仍有限，调用方仍可显式收紧；单文件1GiB、累计4GiB及既有文件数/事件数上限不变，认证、损坏拒绝和超限诊断不变。测试覆盖超过旧时间边界的扫描、默认上限和显式短时限；并不表示对4GiB真实历史做过性能验收。
- 原生集成测试在确认实例复用后立即读取注册记录，避免昂贵进程/监听快照结束后窗口已正常关闭的采样时序问题；保留原有窗口时长、超时、无TCP监听、退出清理和陈旧登记恢复检查。

## 验证范围

本机真实Windows WebView2完整集成3项通过；Linux Chromium浏览器、真实HTTP/CSP集成和资源检查50项及21个子测试通过，1项Windows专属用例在Linux跳过。实际原生低高度窗口、偏好重启、设置和当前显示器DPI检查通过。触控36px与100%–200% DPR属于浏览器模拟，不替代物理触摸屏或跨显示器验收。

本机普通Windows HTTP回环仍受既有环境限制，未修改网络规则；Windows默认原生入口与Linux普通HTTP入口分别实测。正式发布继续通过现有线上构建及renderer资格门禁。

同一版本批次提供core、plugin-core、SkillHub及可选组件，附SHA256校验。轻量导入包继续受200文件上限约束；提供SkillHub包不表示已经上架或获得平台审核。

## English summary

Document panel controls now use compact SVG icons in the existing visible toolbar. Hiding project navigation reclaims its entire column while preserving panel preferences, focus, reading position and native Windows behavior. Stage discovery retains authenticated, bounded scans with a 120-second default time budget and caller-defined tighter limits. Existing resource caps, integrity checks, release qualification and packaging limits remain in place.
