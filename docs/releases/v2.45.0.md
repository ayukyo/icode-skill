# ICODE v2.45.0 — 受保护端口精度与控制面口径一致

本次更新修复了一次 `demo` 端到端实跑暴露的三处控制面缺陷：终审按合同回写计划反而被判漂移、Git 瞬时读取失败被误报成工作区漂移、文档声明可选而门禁要求必填。三处都属于"照合同执行必然失败"级别，会持续消耗每一次运行。

- **受保护端口支持章节级保护（`ignore_sections`）**：`audit` 的 `final_plan` 端口改按「`## 实现偏差备忘` 之前的正文」取摘要。终审回写偏差备忘段不再触发受保护输入漂移，而**计划正文任何改动仍然报漂移**；`code`/`deepcheck`/`patch`/`readme` 的同名端口保持整文件保护。摘要同时对尾部空行归一化，使"定稿时预留空备忘段"与"终审才追加"得到相同结果。
- **`workspace_git_head` 端口改为 fail-closed**：此前 `git rev-parse` 超时时异常被吞掉，`roots` 变少导致摘要消失，进而被当作"工作区变了"——实测 HEAD 全程未变却 block 一次。现在区分三种情况：无 `git` 可执行文件或目标不是仓库（稳定结论，行为不变）、超时/其它 `OSError`/HEAD 读取失败（抛 `ControlError`，`gate_id=step_ports_transient`）。
- **新工单出生即写 `requirement_deltas: []`**：`references/` 文档声明该字段可选且"缺失视为 `[]`"，但完成态 `transition` 走 `--strict` 要求显式存在，导致 `plan → plan_done` 被卡。改为在 `create` 出生处补齐空数组，两处口径一致；用户显式传入的值不被覆盖。

## 验证边界

`execution_model` 契约测试、`fast_risk_upgrade` 契约测试、`control_plane_{metadata,transition,regression}` 契约测试全部通过（PASS 8 / 13 / 26 / 13）；`test_execution_profile*.py`、`test_fast_admission.py` 与新增端口测试共 162 passed / 2 skipped。新增 `tests/test_step_port_protection_unit.py` 10 条用例，端口用例直接读真实 catalog，避免测试与契约各自漂移。

文档同步更新 `references/execution_model.md`（端口契约）与 `references/dir_and_metadata.md`（`requirement_deltas` 出生行为），并重算对应 `source_sha256` 哈希钉。

本机全量 `pytest tests/` 有 10 个模块因未安装 `yaml` / `pptx` 无法收集（环境缺依赖，非本次改动引入），这些模块由 CI 覆盖。

## English summary

Fixes three control-plane defects found by an end-to-end run. The `audit` step now protects only the plan body of `final_plan` (`ignore_sections: ["## 实现偏差备忘"]`), so the contract-mandated write-back of the implementation-deviation memo no longer registers as protected-input drift while genuine body edits still do. The `workspace_git_head` port now fails closed with `step_ports_transient` on transient `git` failures instead of silently shrinking its digest and being misreported as workspace drift; a missing git binary or a non-repository target keeps the previous stable "no facts" result. New tickets seed `requirement_deltas: []` at birth so the documented optional field and the strict completion gate agree.
