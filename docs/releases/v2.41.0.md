# ICODE v2.41.0 — 受管 Node MCP 直启

默认 context7、memory、playwright 和 sequential-thinking 改用固定版本、锁定传递依赖的受管包。注册直接指向 Node 与包声明的 CLI，npm 只在安装阶段执行，运行时省去 npx/npm 启动层，默认 MCP 清单仍为9项。

- 固定当前已使用的包版本：context7 4.7.0、memory 1.0.0、playwright 0.0.85、sequential-thinking 1.0.0。使用完整公共依赖锁和完整性校验，不在每次启动时追随 latest。
- 运行时位于用户私有状态目录，以服务及锁摘要寻址；隔离安装、校验后原子发布，重复安装验证后复用。升级按原回执验证旧包，再安装新锁；配置写入前记录待完成状态，中断重试不丢失受管归属。安装失败不破坏旧可用包，旧运行时和 npm 缓存不自动删除。
- 各宿主分别保留 CLI 参数、环境、工作目录和兼容选项。可识别的旧 npx 启动链转换为直启；未知/自定义条目默认保护，明确收编需绑定原节点摘要。Codex 保持官方 CLI 配置路径。
- memory 显式保留旧有效图谱路径及继承环境变量语义，避免包目录迁移后切换到空图谱。全新安装的数据目录与包版本分离；真实用户图谱不作为测试数据。
- 保留思考日志的隐私默认与用户显式配置，服务名、工具及资源协议保持原实现。现有 npx 会话通过正常重载退出，不强制关闭其他 AI 会话。

## 验证范围

发行验证包含包锁和运行时损坏/失败用例、宿主配置迁移、Windows/POSIX 安装兼容、四包真实 stdio、临时 memory 图谱持久化与资源订阅，以及受控进程树对照。浏览器、模型及其它业务子进程的开销单独计算，不能把启动层工作集求和当作整机可释放内存。

## English summary

Launches four default Node MCPs directly from version-pinned, integrity-checked managed packages. npm runs during installation only. Host-specific settings and existing memory data paths are preserved; service names and the nine-service catalog remain stable.
