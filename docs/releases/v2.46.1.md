# ICODE v2.46.1 — SKILL.md 可移植元数据预算修复

补丁版本。v2.46.0 发布后 `main` 上的 `Public site` 工作流在 `Offline regression tests` 失败，本次把它修掉；产品行为无变化。

- **失败原因**：`tests/test_skill_discovery_metadata.py` 要求 `SKILL.md` ≤ 50 KiB（可移植元数据体积上限）。v2.46.0 新增的「非 ASCII 文本入参」小节把文件从 50,827 B 拉到 52,008 B（LF），稳定超限。
- **修复方式**：把完整规则（Windows 假 stub 判定、UTF-8 文件入参、落盘回读、文件/内联参数互斥）移入 `references/dir_and_metadata.md` 新增的「跨平台 CLI 规则」段；`SKILL.md` 的「Python 解释器解析」只保留一段精简摘要与指针。修复后 `SKILL.md` 为 50,697 B（LF）/ 51,065 B（CRLF 工作树），恢复在预算内。
- **无行为变化**：仅文档位置调整；控制面、候选侧库、出生与归档逻辑均未改动。

## 验证边界

在 WSL Ubuntu-22.04（与 CI 同发行版）按 `public-site.yml` 的 `Offline regression tests` 顺序完整复现：修复前 `test_skill_discovery_metadata.py` 在 `test_portable_metadata_has_valid_identity_and_size` 失败（52,387 B），修复后 21 条命令全部通过（含 `test_skill_discovery_metadata.py` 17 passed、`test_control_plane_verify_doc_contract.sh` 9/9、`test_project_intake_contract.sh` 5/5）。本地 release 资产构建与 SHA256 校验通过。

## English summary

Patch release fixing a red `Public site` run on `main` after v2.46.0. `tests/test_skill_discovery_metadata.py` enforces a 50 KiB cap on `SKILL.md`; the new non-ASCII argument section pushed the file from 50,827 B to 52,008 B (LF). The detailed rules now live in `references/dir_and_metadata.md` under a new cross-platform CLI section, and `SKILL.md` keeps a one-paragraph summary plus a pointer, restoring the file to 50,697 B. No behavior changes: control-plane storage, birth, archive and candidate handling are untouched.
