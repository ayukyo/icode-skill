# ICODE v2.34.0

Technical SVG diagrams can now feed Markdown, DOCX and PPT from the same source.
The isolated runtime pins resvg-py/fonttools/python-pptx; generation and release
qualification use open-source resvg, managed LibreOffice/Poppler and Noto CJK.
Microsoft Office and WPS are optional compatibility checks, not dependencies.

- Validate bounded static SVG, local font glyph coverage and rendering budgets;
  cache PNG fallbacks by source, renderer, fonts, physical width and DPI.
- Build Word from relative SVG images with separate source/embedded hashes,
  alt text and drawing-aware package inspection. PNG remains the default;
  experimental dual mode preserves SVG with PNG fallback and pending consumer
  status until actual qualification evidence is available.
- Insert or replace PPT images through strict template slots or explicit
  regions, preserving aspect ratio, shape identity and z-order. Validate source,
  expected placeholder/hash, original slide numbers, geometry and final media.
- Export sequence diagrams as native text/vector SVG while preserving the
  existing PNG backend. Add three Chinese route/timeline/exception fixtures.
- Qualify actual LibreOffice PDF export and format round-trip for raster/dual
  DOCX/PPT, including retained source SVGs and PNG fallbacks. Visual review is
  recorded separately from machine checks; CI runs the repeatable consumer gate.
  The pinned Poppler image inventory also rejects rasterized dual PDFs, so
  packaged SVG presence alone cannot pass native-vector qualification.
- Keep shared tools in the optional DOCX component and generated assets outside
  Agent discovery. Core/plugin-core/SkillHub imports retain the 200-file gate.

Use the same-version `docx` and `ppt` components for SVG presentations. Run
`tools/docx/bootstrap_runtime.py` and `bootstrap_renderer.py`, then use the
returned managed Python. PPT's explicit `render_slides.py --managed` never
falls back to arbitrary PATH engines. Unsupported SVG features, missing glyphs,
invalid targets and incompatible runtimes fail explicitly.
