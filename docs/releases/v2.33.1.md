# ICODE v2.33.1 — 轻量发行与按需组件

本版补齐轻量包的正式发行链。此前 core 构建虽已通过本地及线上回归，Release 仍只上传完整归档，组件 URL 因缺少附件而无法供普通用户使用。现将完整包、单技能核心包、核心插件包和五个组件作为同一版本的一批附件生成、核对和发行。

- 保留原 `icode-v2.33.1.tar.gz` 及对应 `.sha256`，完整安装方式继续有效。
- 新增 `icode-v2.33.1-core.zip` 和 `icode-v2.33.1-plugin-core.zip`；核心插件展开不超过 200 文件、5 MiB，入口不超过 8 KiB，超预算时构建失败。
- 同批提供 `ppt`、`docx`、`mcp`、`ui`、`support` 五个组件 ZIP、总 `SHA256SUMS` 和 `release-assets.json`。组件的名称、大小和 SHA-256 与核心 manifest 一致；核心加全部组件须与完整工作流逐文件对应。
- 两个 profile 的插件元数据和共享技能也须一致；拒绝 Windows junction 输出重定向，核心入口统一生成 LF，防止 Windows 下 frontmatter 重复回车影响解析。
- 轻量 SKILL 指导 Agent 自动获取同版本组件并准备发现目录之外的运行根。用户无需手动寻找扩展；离线时可显式指定 ZIP。资源准备成功不代表业务功能或宿主执行验收通过。
- 修复 Windows cheap-research/vision-bridge 安装器的解释器注册路径，以及适配器省略 cwd 导致的诊断误报。
- 固定 LibreOffice 资源使用供应商官方历史归档，保留原版本、长度及摘要；真实安装与渲染仍是发布门禁。

## 资源许可与平台边界

轻量包不携带 PPT 二进制模板；PPT 组件继续保留原 NOTICE。第三方模板及预览仅限其授权范围内的个人学习、研究和非商业用途，不能把完整发行统一视为所有素材均采用 MIT，也不因单独下载而改变许可。

发行包完整性、平台收录和宿主实际运行分别验证。Smithery、agentskill.sh、skills.sh Pack 的历史载荷问题仍需按平台实际结果复查；提供新附件不表示这些平台已完成刷新。SkillHub 必填元数据、文件类型过滤和账号审核仍需官方预检，不能仅凭文件数达标宣称已上架。

## English summary

The release now builds and publishes one consistent batch containing the legacy full archive, lightweight skill/plugin archives, five version-pinned components, and checksum receipts. The existing renderer qualification remains mandatory. Component preparation preserves the scanned skill directory and verifies every archive before use. Third-party PPT asset restrictions remain unchanged; registry ingestion and real host execution are separate verification steps.
