# ICODE v2.33.2 — 统一源码命名与平台出包规则

SkillHub 实际发布先后拒绝 `.gitignore`、无扩展名 `LICENSE` 和 `.json.template`。本版将这些问题纳入源码、构建器与测试，不再维护手工修改的上传 ZIP。

- 根许可统一命名为 `LICENSE.txt`，保留原许可正文；JSON 模板统一为 `*.template.json`，包含四份配置模板及三份插件清单模板。调用方、双语文档、官网许可链接和测试引用同步更新。
- `.gitignore` 作为开发资料放入 support 组件。full 保留全部公开资源，core 加全部组件仍须逐文件还原 full。
- 同批构建新增 `icode-v2.33.2-skillhub.zip`：由已冻结的核心快照生成必填元数据，排除可选图标/UI 元数据，重算核心文件清单，沿用完全相同的组件地址和摘要。许可与功能资源来自统一源码。
- 供 Agent 导入或平台上传的 core、plugin-core、SkillHub 包展开后均不得超过 **200 个文件**；清单、许可证、图标和共享技能都计数。超限构建失败，新增 200/201 文件边界回归。组件继续在扫描目录外准备。
- SkillHub 包仅接受本工程当前使用的标准文本后缀并严格按 UTF-8 校验；未知文件类型在发行前失败。该本地门禁不等同平台审核承诺。

既有完整包命名、渲染资格门禁和明确发布授权要求继续适用。新版本组件尚未公开前，不能将候选中的下载地址称为可用；已发布的 v2.33.1 附件不覆盖、不改写。
