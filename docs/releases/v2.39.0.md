# ICODE v2.39.0 — 安装收敛与 MCP 降级兼容

重新安装时按当前发行收敛 ICODE 受管 Skill/MCP，避免删除或合并后旧入口继续累积；修复 sequential-thinking 未暴露时文档允许降级、校验器却强制真实调用的矛盾。

- 保持共享 Skill 所有权标记兼容，新增发布内容摘要。仅将归属明确且未被用户改写的退役 Skill 归档到扫描目录外；无历史摘要、用户修改或归属不明的项保留并报告冲突。
- MCP 使用所选宿主的注册摘要与发行清单；新版所选服务全部安装并通过注册校验后，才注销受管退役服务并归档代码、配置与运行时。旧版接管要求实际注册完整匹配已有导出，回执不保存凭据正文。
- 根安装、直接 MCP 安装与同步脚本复用收敛逻辑。单项安装不清理其他服务，非 Claude 安装不改写 Claude 注册；失败保留恢复状态，支持重试。
- `--dry-run` 零写入，`--no-delete` 暂缓退役，`--skip-mcp` 不改变 MCP 注册或回执。注册变化在宿主重载或新会话后生效，安装器不结束其他会话。
- sequential-thinking 未暴露时允许 `attempted=false` 的明确降级记录，要求发现依据、替代方法及实际思考证据。保留 L2/L3 机制要求及旧真实调用记录兼容，仍拒绝缺证据或伪造成功。
- 同步其他 MCP 门禁的未暴露说明，补充全部 12 个覆盖 gate 的正反例；Claude 配置和导出文件使用唯一私有暂存文件并检查链接路径。

## 验证与能力边界

Linux 原生定向回归 204 项及 15 个子测试通过，10 组 Shell 契约通过；Windows 主工程定向复验 130 项通过，6 项平台或链接权限相关用例跳过。线上构建与发布以本版本提交对应的 Actions 结果为准。

归属不明或被改写的历史安装项不会被强行清理。归档保留恢复数据。此次未合并 MCP 服务，也没有宣称减少后的性能实测；真实宿主重装、运行中会话重载与设备行为需分别验证。

## English summary

Reinstallation reconciles provably ICODE-managed, unchanged Skills and MCP services against the current distribution, with external archives, per-host registration verification, conflict retention and retry support. Unexposed sequential-thinking tools can use evidence-backed degradation without fabricating a call. Existing invocation traces, ownership markers and host boundaries remain compatible.
