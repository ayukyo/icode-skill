# ICODE v2.42.0 — fast 风险分流与工单产物减重

fast 按已界定的范围和实际风险选择执行路径，工单优先通过现有概览阅读，重复候选清单使用可完整还原的引用存储。六阶段、TDD、Reverse/Audit 的真实读取及后续 patch、独立 crosscheck 合同保留。

- 新 fast 工单采用风险策略 2。范围明确的跨文件、缓存或实机任务可继续 fast，并落实相应影响、生命周期和实机验收合同；新架构、无界影响、破坏接口、不可逆迁移或必需独立对抗评审走 full。未决语义和重大增量先阻断或回计划。已有旧工单沿用原策略，full 空风险表与已知布尔子集保持兼容。
- 复用 `delivery_validation_report.md` 作为工单概览，支持独立 Markdown 输出，在主流程或 patch 稳定完成时刷新同一文件。紧凑上下文分别呈现状态、候选时效、验证债务和材料入口；fresh crosscheck 在读取前排除旧概览、旧裁决及相关 findings 扫描。
- 新支持工单采用物理存储版本 2：重复候选数组从同一工单已提交的事件定义中按完整摘要还原。逻辑对象、候选 ID、事件哈希与来源记录保留；旧 inline 工单不自动迁移，旧事件前缀不重写。中央事务、恢复、归档、阶段发现、读取者、UI、linter 和步骤示例一起适配。
- 强化损坏 journal 的回滚锚点、证据最终超时、真实父 junction/symlink 路径边界，以及悬空 pending 事务的报告写入保护。阶段诊断保留 legacy JSON 错误语义与真实协调票失败位置。
- 核心导入文件预算仍为 200。运行时 helper 保留在核心包，开发探针随 support、原生 UI 自检随 UI 组件发行；没有新增 MCP 服务或后台进程。

## 兼容与验证边界

新物理格式需要本版配套读写器；应整体更新安装。旧格式继续可读，历史文件不自动清理。运行中的 AI/MCP 会话需正常重载或新建会话后采用更新。

本地相关软件矩阵：Linux 1451 passed、750 subtests passed；Windows 420 passed、55 subtests passed。平台跳过分别为 3 与 13 项，真实链接/Bash 用例由相应平台覆盖。七套流程/控制面 Shell 契约、独立规格与质量审查通过。

664 行、18 份完整候选的隔离生产 writer 压力样本中，重复内容总写入中位数从 21,856,232 降至 273,500 bytes（约 98.7%），包含 journal、metadata、event 与必要的再次 compact，fsync 保留。首次集中写入和部分只读仍有额外开销；此结果不是实际模型六阶段、真机或完整 fast/LLM 耗时的加速比例。

## English summary

Adds versioned, scope-bound fast routing, a single ticket overview entry point and lossless candidate-manifest reference storage. Preserves workflow gates, original logical identities, legacy inline history, patch continuity and independent crosscheck boundaries. The core import budget remains 200 files; no new MCP service is added.
