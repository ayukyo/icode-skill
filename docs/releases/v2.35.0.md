# ICODE v2.35.0 — DOC 文档库与 Windows 原生工作台

本版把 DOC 生成的工程文档、分支、模块快照和章节接入独立文档库，并完成 Windows 无 TCP 网页窗口及与官网一致的工作台视觉。

- `/icode ui` 可在没有工单时阅读文档，按工程、分支、模块和快照切换，支持章节树、章内目录、正文搜索、绑定模块往返、阅读位置恢复及专注模式。历史审核、正文完整性和当前源码核验状态分别显示；阅读不改写原文档。
- Windows x64 默认使用 WebView2 网页窗口，HTML/API 经私有进程管道复用现有业务，不建立 UI TCP 监听，也不修改防火墙。当前用户专用控制管道核对实例、PID、创建时间和窗口，重复启动复用窗口；修复并发首次准备缓存及高 DPI 地址栏布局。
- 工单、驾驶舱、设置、弹窗和文档库统一使用官网浅薄荷背景、白色卡片、深蓝文字和青绿控件。保留既有令牌、Origin、CSP、Mermaid 沙箱和受控步骤门禁。
- Linux/macOS 默认普通浏览器；Windows 显式 `--browser`、`--port` 和 `--no-browser` 保持 HTTP 兼容。Windows 原生模式要求64位 Python、.NET Framework 4.8 和 Evergreen WebView2。固定官方 SDK 按大小/SHA256验证后在外部缓存编译；缺少依赖明确报错，不静默回退或自动提权安装。
- 继续提供完整归档、core/plugin-core/SkillHub ZIP、五个同版本组件及校验清单。导入包保持≤200文件；UI运行依赖、编译产物和用户文档不进入技能导入树。

## 验证范围

Windows 10 本机完成185项原生测试、真实7套/146章/70张图阅读，以及搜索、绑定模块、刷新/重载位置恢复、宽窄屏和200%DPI整窗测试；原始4262个MD/JSON文件摘要未变。Windows CI同时要求真实WebView2/管道/CLI测试和54项HTTP兼容测试；版本发行继续经过真实DOCX renderer资格门禁。

平台收录、消费者兼容与发行附件完整性分别验证。PPT第三方模板沿用既有NOTICE许可边界；提供SkillHub包不代表已经在SkillHub上架或通过审核。

## English summary

The workbench now reads generated DOC libraries across projects, branches and exact module snapshots. Windows defaults to a WebView2 webpage window using private process pipes, with no UI TCP listener or firewall changes. The website palette is shared across ticket management, settings and document reading. Existing HTTP modes remain available. All release archives and optional components are built as one version-bound, checksum-verified batch; lightweight imports retain the 200-file limit.
