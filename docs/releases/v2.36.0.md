# ICODE v2.36.0 — 清晰显示与更宽的文档阅读区

本版改善 Windows 原生工作台的显示适配、顶部操作和 DOC 阅读空间。

- Windows 原生窗口启用 .NET Framework 4.8 PerMonitorV2，按所在显示器 DPI 和工作区适配窗口，处理 DPI 变化。启动配置在外部运行时缓存生成并独立校验，不依赖特定电脑的分辨率或缩放补偿值。
- 原生设置入口移入上方导航工具栏，移除文档页重复顶栏；连接状态和刷新时间保留为紧凑信息，错误状态仍可见。HTTP 浏览器模式保留网页操作入口。
- 工程导航、章节树和本章目录可分别收起与展开，保存显示偏好。专注阅读保存并恢复进入前的侧栏状态；切换工单及调整导航不会覆盖隐藏文档的阅读位置。
- 宽 SVG 保留自然尺寸并支持横向滚动，正文保持舒适行宽。中窄屏使用独立导航区域；矮窗口按可用阅读区分配导航高度，保留可阅读正文和恢复入口。
- 继续复用私有进程管道、当前用户控制管道、令牌、Origin 检查、CSP 和 Mermaid 沙箱。缺少依赖明确报错；不修改防火墙或原始文档。
- 完整归档、core、plugin-core、SkillHub 和五个可选组件以同版本批次发布，附 SHA256 校验。实际导入包仍在 200 文件上限内，原生编译产物与用户运行时留在安装树外。

## 验证范围

本机 Windows 原生 host、CLI、缓存、管道、实例和阅读器共193项测试通过。Linux Chromium 的 HTTP/DOC 链路67项通过，另19组子测试通过；其中包括5档模拟DPR与两种视口，以及低高度窗口展开、收起和恢复组合。模拟像素比不等同于不同物理显示器的验收。

实际 Windows 和全局安装入口完成7套文档、146章、70张SVG图及搜索、目录、模块往返、刷新和阅读位置恢复检查；原始4262个MD/JSON文件摘要未变。当前实际显示器验证 DPI 与页面像素比匹配；不同物理DPI多屏之间拖动、运行中改变系统缩放尚未覆盖实机环境。

发布继续受 Windows UI/HTTP、文档渲染器资格、安装包完整性与文件数门禁约束。PPT第三方模板沿用既有NOTICE许可边界；提供SkillHub包不代表已经上架或通过平台审核。

## English summary

Windows now uses monitor-aware DPI rendering and a compact native toolbar. Project navigation, chapter navigation and the document outline collapse independently and retain user preferences. Focus mode restores the previous panel arrangement, wide SVG diagrams retain readable labels, and short windows keep room for document text. Existing private transport and document safety boundaries remain in place. Release assets and optional components remain version-bound and checksum-verified, with lightweight import packages below the 200-file limit.
