# 本地 MCP 路径访问合同

本合同适用于复用 `mcp/_lib/local_mcp_common.py` 的 workspace、evidence、local-index、mcp-health 和 device-observe 本地路径读取。目录读取、远端设备路径、受管写入和可执行服务信任是不同权限，不互相推导。

## 平台默认与显式限制

`allowed_roots: null` 或省略该字段使用平台默认：

- Windows：按请求访问实际本地固定磁盘、可移动磁盘和 RAM 磁盘；不以用户目录作为项目边界，不扫描或建立全盘索引。标准 WSL 本地 UNC 视图按实际路径检查；普通远端 UNC/网络盘不属于此默认。
- Linux/其它 POSIX：沿用用户目录默认。WSL 内运行的 MCP 使用 Linux 路径视图和该端配置；Windows MCP 与 WSL 构建进程不能交换未经核验的路径字符串。

非空 `allowed_roots` 数组是用户显式白名单，包括 `["$HOME"]`，优先于平台默认。空数组、无效类型和无可用根须明确失败，不作为无限制访问。符号链接/reparse point 的最终位置仍须满足对应政策；默认访问本地磁盘不代表可经链接转向远端或受保护凭据。

Windows 平台默认保护已知的凭据文件和秘密目录；批量证据摄取和索引也在子文件读取前应用同一保护，并保留跳过/不完整边界。它不是 DLP 或内容秘密检测；不通过源码中的 `token`、`cookie` 等普通符号判定文件不可读。显式白名单保持既有访问语义，操作者须按任务约束管理读取范围。

## 接入与诊断

进入工程读取前根据能力描述确认服务路径策略。路径拒绝时区分：平台默认不含该路径、显式根限制、敏感路径保护、路径不存在、操作系统文件权限、配置损坏。拒绝访问只证明该 MCP 无权读取，不能证明工程不存在或不可构建。

服务配置优先读取对应 `ICODE_*_CONFIG` 环境变量指定的文件，否则读取该服务目录的 `config.json`；配置文件不存在才使用程序默认。返回的访问诊断只帮助定位范围，不能代替用户授权或自动修改配置。

固定 Git/制品/设备只读探测命令使用独立的 EOF 标准输入，不继承 MCP 协议管道；协议输入本身保持不变。这防止子命令读取或等待协议数据，不放宽命令、执行信任或远端目录范围。

需要访问显式范围外的路径时，说明实际政策和最小配置差异，保留原文件；不能悄悄把显式白名单换成平台默认，不能以扩大读取范围为理由修改项目、设备或系统设置。原始读取始终受工具自己的文件/字节/深度/时间预算限制，工具调用成功只覆盖已观测范围。

## 更新与迁移

新版示例使用平台默认。旧安装若已有 `allowed_roots: ["$HOME"]`，更新代码仍保留这一显式配置；普通技能同步不覆盖真实 `config.json`。

迁移旧默认配置前，先比较它与对应旧版公开示例是否一致，展示具体文件、前后政策与备份位置。经用户授权后只修改该字段，不覆盖其它配置；定制白名单保持不变。文件更新不代表当前 MCP 进程已重载，必须分别核验新代码/配置以及当前会话实际调用。

## 不随本地读范围扩大的边界

| 边界 | 独立约束 |
|---|---|
| workspace/evidence | 固定只读操作、有界扫描；不执行工程脚本探测 |
| local-index | 源文件只读，仅既有受管数据库目录可写 |
| mcp-health | `trusted_server_roots` 仍决定哪些服务可被启动探测 |
| device-observe | 命名 profile、`allowed_remote_roots` 与 fixture 内部根保持；不提供部署/重启/刷写 |
| mail-observe | 凭据、只读邮箱和附件输出合同不因本地读策略改变 |
| cheap-research | 使用其独立 `CHEAP_RESEARCH_ALLOWED_ROOTS`/配置合同；不能假定共享层策略已覆盖它 |

构建跨 Windows/WSL 时另读 [WSL 构建合同](wsl_build.md)，分别固定两端路径、环境和制品身份。
