# Claude Code / Codex 宿主适配契约

共享 SKILL 描述“要完成的操作”，ICODE 在运行时映射到当前宿主可用工具。方法论只有一份，工具语法不进入共享技能正文。

| 抽象操作 | Claude Code 适配 | Codex 适配 | 无能力时 |
|---|---|---|---|
| 读文件/文本检索 | Read、Grep、Glob 或 shell `rg` | 文件读取工具或 shell `rg` | 使用当前宿主最窄只读命令 |
| 结构化思考 | 已注册的 sequential-thinking MCP | 当前可调用的 sequential-thinking MCP | 输出显式结构化思考块 |
| 独立审查 | 后台 Agent + 有界等待 | collaboration 子代理 + 有界等待 | 标记无独立审查环境，不由主代理伪装 |
| 外部文档/媒体 | 当前已注册 MCP | 当前已注册 MCP 或本地 CLI | 声明降级，保留未观测边界 |
| 文件修改 | 宿主提供的精确编辑工具 | `apply_patch` | 停止修改，不用不安全覆盖命令替代 |

## 共同约束

1. 先探测能力，再选择适配；禁止假定某个 MCP、Agent 或命令一定存在。
2. 相同抽象输入必须产出相同字段语义，不能因宿主不同改变事实/推断判定标准。
3. 子代理只提供候选或独立裁决；主代理负责证据复核、范围控制和最终结论。
4. 宿主降级只降低自动化程度，不降低证据要求；无法验证就保留 `unobserved/inconclusive`。
